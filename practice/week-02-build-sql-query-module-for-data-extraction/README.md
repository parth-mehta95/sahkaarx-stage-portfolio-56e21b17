# Build SQL Query Module for Data Extraction

## Task Brief
Create a SQL module with SELECT and GROUP BY queries to extract and aggregate data from sample database.

## Scenario
Analytics team needs reusable SQL functions to fetch and group customer transaction data for the pipeline.

## Deliverables
- sql_queries.py with SELECT and GROUP BY functions
- Sample SQLite database schema
- Query test cases

## Success Criteria
- SELECT queries return correct row counts
- GROUP BY aggregations match expected totals
- Functions accept parameterized inputs
