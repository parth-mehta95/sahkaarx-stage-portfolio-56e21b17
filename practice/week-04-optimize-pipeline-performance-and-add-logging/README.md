## Task Brief
Implement performance monitoring, error handling, and structured logging across the complete data pipeline.

## Scenario
Data engineering team requires robust error handling and performance metrics for production deployment of the pipeline.

## Deliverables
- logging_config.py with structured logging
- error_handling in all modules
- performance_metrics.py with timing utilities

## Success Criteria
- All functions log entry, exit, and errors
- Pipeline tracks query and transformation times
- Errors are caught and logged without crashing
